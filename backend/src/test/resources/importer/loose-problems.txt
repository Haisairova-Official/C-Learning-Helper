第1题：两数之和
分值：10 分
时间限制：1000ms
内存限制：128 MB
题目描述：读入两个整数，输出它们的和。
输入说明：两个由空格分隔的整数。
输出说明：输出和。

Sample Input 1:
1 2
Sample Output 1:
3

参考代码：
```c
#include <stdio.h>
int main(void) {
    int a, b;
    scanf("%d%d", &a, &b);
    printf("%d\n", a + b);
    return 0;
}
```
