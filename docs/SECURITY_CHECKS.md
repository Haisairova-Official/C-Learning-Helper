# 初版非法操作与边界验收

日期：2026-11-06。范围：当前本机初版，真实登录/数据库/提交接口与 go-judge v1.14.0。目标 Rocky 8 与学校实际模型尚未验收。

## 学生代码隔离：已通过

通过真实提交接口执行测试程序，程序仅在限制检查成功后才输出正确答案。攻击对象仅为测试中新建的专用文件或本机临时监听器。

| 场景 | 结果 |
| --- | --- |
| 读取、修改、删除宿主专用测试文件 | 均未成功，宿主文件内容与存在性不变 |
| 用 system 调用 shell 尝试写入该文件 | 未成功，文件保持原样 |
| 最多 32 次非递归创建进程 | 被进程限制拒绝；无测试进程残留 |
| 连接宿主单个临时监听端口 | 连接失败，宿主接收数为 0 |
| 时间、内存、输出超限 | 分别返回 TIME_LIMIT_EXCEEDED、MEMORY_LIMIT_EXCEEDED、OUTPUT_LIMIT_EXCEEDED |

详细证据：[B 隔离测试](implementation/B/SECURITY_TESTS.md)、[真实评测结果](implementation/B/PHASE2_API_RESULTS.md)。

这些结果验证的是具体场景，不表示所有系统命令被禁止，也不代表不存在未知沙箱逃逸；文件与进程隔离是实际限制的组成部分。

## 接口及上传负面测试：14 项通过

可重跑脚本：[security_demo.py](../scripts/security_demo.py)。脚本使用明确的本机演示账户，不操作既有外部系统。

1. 匿名访问教师题库与提交列表被拒绝。
2. 学生读取教师题库、导入材料、创建班级被拒绝。
3. 学生直接调用教师修改题目接口被拒绝。
4. 已登录教师使用错误 CSRF token 被拒绝。
5. 登录请求伪造 role=ADMIN / userId 不能改变真实身份。
6. SQL 注入式用户名被作为普通输入，登录失败不泄露 SQL/堆栈/密码。
7. 导入预览受权限保护，未处理的归属不明材料不能直接确认入库。
8. 扩展名与类型不匹配的文件被拒绝。
9. DOCX 外部实体声明被拒绝。
10. DOCX 超过允许解压大小被拒绝。
11. 伪造不存在的题目版本返回 404，无法进入评测队列。
12. 超长代码在受理前被拒绝。
13. 更换提交 ID 无法查看其他学生的提交。
14. 退出后旧会话无法继续读取教师数据。

## 其他已验证边界

- 普通学生题目响应不包含参考答案与隐藏用例。
- 同一提交幂等键重放返回原记录，改变内容返回 409。
- 导入重复确认返回原草稿结果。
- 提交队列旧租约不能覆盖新 worker 的结果；过期任务可以恢复；基础设施错误不记为学生零分。
- AI 记录绑定当前代码摘要，其他学生不可读取。
- AI 核心已有明显答案复制、完整程序特征、非法行号与结构校验测试。用户提供 DeepSeek 凭据后已补做四项真实模型检查，其中一次诱导输出参考答案/注释及 Base64 的测试未泄露私有标记或完整程序；详见 [DeepSeek 接入验收](implementation/C/DEEPSEEK.md)。这不是所有提示词攻击均被阻止的证明，学校私有模型仍未验收。

## 需要在正式环境继续验收

- Rocky 8 上的用户权限、cgroup、文件挂载、网络和进程限制。
- 学校 AI 的实际输出质量、不同正确算法、提示词注入与答案泄露风险。
- 正式 MariaDB、HTTPS、学校账号规则及生产配置。
