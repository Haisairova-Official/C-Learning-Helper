# 第二轮功能扩充与验收

日期：2026-11-06。本机真实服务已加载 V5–V7；沿用项目私有 MySQL 开发实例，正式 MariaDB/Rocky 8 不在本次验证范围。

## 完成内容

- 作业上一题/下一题、可点击题号、展开目录、四色历史最佳状态与动效。窗口聚焦、回到前台及定时刷新；会话到期保留标签页草稿。
- `/settings` 昵称、头像、bio、三种固定 AI 回复风格。头像检测真实类型、限制字节与尺寸、重新编码 PNG；资料仅本人修改。
- 学生左下角显示真实班级与独立学号，资料区域进入设置，退出按钮独立。V7 新增可空学号；只在 demo 初始化时为两个演示学生补空学号20260001/20260002，保留已录入的学号及用户昵称/头像。教师名单同步使用学号字段；教师/管理员资料区保留角色与登录账号。
- 完整程序和函数题都支持 C17 / C++17。函数题以教师私有主程序组装学生函数，经固定 GCC/G++ 编译配置执行；原始提交单独保存，学生接口无参考答案及私有主程序。
- Easy Parse 新增单题对象、数组、problems 包的 JSON 识别，保留题型、语言、公开接口、起始代码、私有主程序、代码限制和样例说明。缺接口/模板可保留草稿，发布必须完整。未知字段需要人工归类，JSON 不自动发布。
- PTA 蓝本实际读取220题：函数30、编程190；另外4道多文件题只收录目录。题意摘要及适配问题是蓝本，未批量冒充可评测题库。总入口见 [PTA_COLLECTION.md](implementation/C/PTA_COLLECTION.md)。

- 全后端 `verify`：123项记录，118通过，5项按环境条件跳过，0失败/错误。跳过包含 SQL 集成与真实评测参数化入口；B单独开启真实评测开关，8个真实隔离用例另行全部通过（两语言函数AC/WA/CE及两语言程序回归）。
- 前端：25项测试及生产构建通过。
