## 修改文件及用途

- `frontend/src/App.vue`：去除侧栏口号与真实服务下的开发环境标记；保留明确的模拟环境标识。
- `frontend/src/views/*.vue`：整理全部九个页面的标题、说明和错误占位文字；保留必要的导入格式、提交规则及数据发送说明。
- `frontend/src/lib/profile.ts`、`lib/ai.ts`：精简风格选项及失败提示；不改变风格枚举或处理逻辑。
- `frontend/src/api/mock.ts`：模拟模式继续如实标识，移除已过时的“尚未接入”说明。
- `frontend/src/router.ts`、`styles.css`：统一导入页名称，移除已删除内容的样式并核对响应式选择器。
- `AGENTS.md`：固化正式教学系统页面文案规范。
