## 修改

- `frontend/src/views/TeacherAssignmentsView.vue`：名称使用原生按钮，支持 Tab / Enter；独立编辑弹窗每次读取当前作业详情，不以旧列表值直接编辑。班级、出题方式、题数只读。保存成功后以服务端返回结果更新列表；加载失败可重试，保存失败保留输入。
- `frontend/src/api/management.ts`：新增教师作业详情 GET 与五字段 PUT，返回 `Assignment`。没有修改公共类型或数据库。
- 名称按去除首尾空白后的 1–200 Unicode 字符校验；时间必须有效，且截止晚于开放。没有修改的时间按服务端原始字符串提交，保留微秒精度；用户编辑的时间按当前设备时区转换为 ISO 时间。
- 用户追加要求已落实：发布与编辑弹窗均使用 Element Plus 日期时间选择器，输入显示 `YYYY/MM/DD HH:mm`，日历日期显示 `YYYY/MM/DD`、时间选择显示 `HH:mm`，无秒/毫秒；绑定值为 `YYYY-MM-DDTHH:mm`。列表截止时间也显示完整年月日与时分。已读取当前 `node_modules` 的 `valueFormat/dateFormat/timeFormat` 类型确认支持。编辑是否变更按分钟展示值比较，不因原时间秒/微秒而误判。
- 编辑按钮在未改动、校验失败、加载或保存时不能重复保存；关闭/重新打开弹窗与离开页面时，不接受旧详情或保存请求的迟到响应。新建发布流程保持原状。
