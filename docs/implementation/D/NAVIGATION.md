# 作业集上一题 / 下一题

日期：2026-11-06。用户要求在作业集作答页提供连续切题，主 Agent 完成。

## 行为

- 在题干和编辑器上方显示当前作业集名称、“上一题”“第 N 题 / 共 M 题”“下一题”。
- 顺序来自已授权的 GET `/api/student/assignments/{id}` 的 problems 列表，沿用教师发布的 position；不按标题或 ID 重新排序。
- 首题禁用上一题，末题禁用下一题；单题作业两侧都禁用，不跳到其他作业。
- 切题前立即保存当前用户、作业和题目版本对应的代码草稿。若浏览器存储失败，保留当前页并提示复制备份。
- 现有 RouterView 以完整路由为 key，切题重新加载题干、草稿、历史和评测区域，避免沿用前一题状态；进行中的服务端分析仍可完成。
- 导航数据加载失败时可单独重试，当前题目仍可作答。窄屏时导航分行显示。
