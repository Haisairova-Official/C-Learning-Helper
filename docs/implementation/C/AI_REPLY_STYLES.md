# AI 回复风格与函数题上下文

日期：2026-11-06。主 Agent 实现；关联 A 账号设置、B 函数题、D 设置页。

## 行为

设置页三种固定风格：CONCISE 简洁直接、GUIDED 启发引导、DETAILED 详细讲解。服务端从当前账号读取，不接受任意自由提示词。任务受理时快照风格；进行中更改设置不会改变已受理任务。GET 分析结果增加 replyStyle，旧记录允许为空。

基础规则仍禁止参考答案、完整函数/算法和替换代码；固定风格只能改变措辞与详略。统一提示词版本 c-debug-guidance/0.4。函数题上下文附语言、公开接口和只需提交函数的说明，避免将缺少 main 当成错误；教师私有 judgeTemplate 不发给模型。教师 referenceAnswer 按原设计仍仅在服务器读取后提供给已配置模型参考。

## 验证

AiGuidanceCoreTest 新增三风格下注入隔离和泄露拒绝、函数类型/语言/接口上下文及私有模板排除；AiAnalysisControllerTest 验证受理后更改设置，后台仍使用原风格并记录元数据。AI 三类定向测试通过。

真实模型验证及统一 HTTP 验收结果由主 Agent 在集成结束时补记；上述单元测试不代表模型始终符合预期。学校私有 AI 仍待接口，当前真实服务为已配置的 DeepSeek。
