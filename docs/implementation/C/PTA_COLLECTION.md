## 采集与评测边界

蓝本是基于实际公开题面的原创简述，保留来源、输入输出重点、样例数量、资源和适配事项。原始完整API响应只进入项目私有调试目录，未把整套题面、参考答案或隐藏测试复制到交付资料。函数题公开接口不等于可用的完整教材类库，编程题分类也不保证算法细节足以建立可靠评测。

190道编程题的真实description已全部读取，API请求没有失败；通用content模板未作为题面。原响应中的源编译器标记均是NO_COMPILER，因此C17/CPP17兼容性仍需独立实现、编译和隔离测试，不能标成直接可运行。图示未逐张视觉复核，依赖图义的条目已注明。

当前最需要处理的差异包括：允许多种答案的特殊裁判题；指定堆形、前驱或中间状态的教材算法；缺少散列公式等定义的题；标题/公式矛盾；以及正文与API样例记录不一致。这些都在逐题蓝本中保留，不能静默猜测。
