## 题意摘要

在递减整数数组中插入一个整数并维持顺序；容量不足或元素重复时操作失败，数组保持原状。要求讨论最好与最坏情况下的时间和空间复杂度。原题使用 C++ 引用、class 和 vector，属于函数补全题。
