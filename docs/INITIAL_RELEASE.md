## 发现并修复的问题

1. 子 Agent 的前端开发进程会随其结束退出。现使用 [独立启动器](../scripts/local_app.py) 将服务转为独立进程，并实际验证端口恢复。
2. 私有 MySQL 冷重启后首次完整认证需要 RSA 公钥。启动脚本现在显式传入本机生成的公钥文件，避免依赖暖缓存，也未开启任意公钥获取。冷重启后连接成功，历史数据保留。
3. 网页真实开发模式原先显示“学校教学环境”，现改为“本地试用”，与实际部署状态一致。
