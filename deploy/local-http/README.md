# 本机局域网 80 端口入口

用于当前开发机：systemd 监听 `0.0.0.0:80`，将 TCP 连接转发到现有前端 `127.0.0.1:5173`。前端 `/api` 继续代理到 `127.0.0.1:8080`，WebSocket 连接同样透传。后端、数据库、评测服务监听地址不变。

## 启用

先启动项目服务，然后在本机终端执行：

```sh
sudo bash '/home/akizuki/Documents/ChatGPT/C语言教学辅助系统/deploy/local-http/install.sh'
```

脚本仅安装本目录两个专用单元、加载并启用该 socket。遇到同名不同配置或端口被其他服务占用时停止，不覆盖已有配置。使用系统自带的 socket 转发程序，不安装软件、不改变防火墙，不给 Node 或普通用户增加全局绑定低端口的权限。

启用后当前访问地址为 <http://192.168.2.100/>。socket 随系统启动；项目数据库、后端、前端与评测服务仍由原项目启动器管理，需要保持运行。

## 停用

```sh
sudo systemctl disable --now c-assist-lan-http.socket
sudo systemctl stop c-assist-lan-http.service
```

停用不会影响原 `5173` 入口。不会自动删除单元文件。
